# Gallery photos

Add as many JPG, JPEG, PNG, WebP, or AVIF images as you want to this folder.
The Gallery page detects every image automatically at build time. The first four
also appear on the landing page, using these file names:

```
gallery-1.jpeg
gallery-2.jpeg
gallery-3.jpeg
gallery-4.jpeg
```

They are displayed without captions in the `From the gallery` section. Any
orientation works: the Gallery page keeps the original aspect ratio, while the
landing page crops the first four neatly to fit their cards.
